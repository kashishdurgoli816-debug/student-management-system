# Student Attendance Management System

T.Y.BSc.CS project by Kashish Sharad Durgoli.

A web app to record student attendance, calculate attendance percentage automatically and generate reports.

## Roles and demo logins
- Admin: `admin` / `admin123`
- Teacher: `teacher1` / `teach123`
- Student: `student1` to `student8` / `stud123`

## Tech
HTML, CSS, JavaScript. Data is saved in the browser (localStorage).

## Run locally
Open `index.html` in Chrome or Firefox.
